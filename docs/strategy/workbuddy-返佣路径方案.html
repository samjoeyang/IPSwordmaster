✓结论先行

你不需要挂靠任何代理商，也不需要交 6 万保证金。走官方的 「腾讯云 CPS 推广大使」即可 —— WorkBuddy 旗舰版 / 专享版已于 2026 年 7 月被正式纳入 CPS 返佣产品目录，这是官方唯一允许「不成为代理商、也能拿销售返佣」的合规通道。

为什么不能挂靠代理商：《合作伙伴权利义务》明文规定，合作伙伴「不得发展下级代理商（包括但不限于二级代理、分包等任何直接或间接与代理性质相同或近似的行为）」。私下挂靠分成是代理商违约，你拿不到任何官方保障，返佣结算完全靠对方自觉。

1四步开通流程

  1. 注册腾讯云账号并完成个人实名认证 —— 注意必须是个人实名，企业实名账号不能成为推广者。
  2. 申请参与推广活动，入口：cloud.tencent.com/act/partner/cps
  3. 获取专属推广链接，从 CPS 控制台复制，发给客户或投放到你的私域 / 内容渠道。
  4. 客户通过你的链接注册 / 登录并在关联期内下单，返佣自动记到你名下，次月 6–15 日月结。
关键口径要先核实：CPS 返佣产品目录里的名称是「腾讯云代码助手 WorkBuddy（旗舰版、专享版）」。给客户下单前，务必在 CPS 控制台的返佣产品详情页确认你要卖的 SKU 在清单内，别买了不在目录里的版本（例如个人标准版 ¥58/月目前不在返佣清单）。

3红线：这些情况一分钱拿不到

情形说明

客户不是新客户近 30 天内有产品保有或消费记录的账号不算新客，只有「沉睡用户」（近 30 天消费为 0）的首笔新购可按 20% 计。

你用企业账号申请资格不符 推广者仅限个人实名用户；企业用户、代理商、腾讯员工及合作伙伴员工均不能参与。
身份互斥个人账号一旦加入推广者，该账号不可再成为代理商账号。两条路只能选一条。

5给你的三条补充建议

① 返佣只是零钱，服务费才是大头

单客户封顶 ¥5,000 决定了这是「顺手赚」而不是「生意」。你真正该收的是落地服务费：把知识产权维权的方法论封装成 WorkBuddy 的 Skill / 专家包（侵权监测、取证固证、投诉文书生成、案件台账管理），给客户做部署 + 培训 + 知识库搭建。这部分收入不受 5000 封顶限制，且完全合规。

② 客户采购时，先确认他账号是「干净」的

很多企业早就买过腾讯云产品、或者已被代理商服务过。在让他下单前，先确认账号状态，否则白忙一场。这也是为什么必须先拿到推广链接再让客户注册，顺序不能反。

③ 别碰第三方「积分兑换码」站

市面上有站点卖 WorkBuddy 兑换码、让你下载配置包写入第三方 API Key。这类是接第三方 API 中转站，官方积分体系查不到，对话内容和代码都会被截取，也会触发 CPS 风控。既不安全也不合规。

?需要你确认的一件事

CPS 推广者只接受个人实名认证。你现在是打算用个人身份收返佣，还是必须走公司账？

  • 个人身份 → 直接按上面四步办，今天就开通。
  • 必须走公司账 → CPS 不适用，那就只有两条路：要么正式申请代理（6 万保证金），要么干脆不拿返佣、只收服务费，把 WorkBuddy 作为你服务方案里的工具推荐给客户，客户自行官网采购。第三条其实最干净，也最贴合你知识产权维权的专业定位。
