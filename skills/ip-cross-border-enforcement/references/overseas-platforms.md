# 境外电商平台投诉机制

> 各平台规则持续调整，执行前以平台当期政策为准。

## 一、Amazon（亚马逊）

### Brand Registry（品牌注册）
- 前提：商标已注册或申请中（美国/欧盟/日本等站点的有效注册商标），商品有品牌。
- 权益：品牌保护工具（Report a Violation）、自动拦截、透明计划（Transparency）防伪码、Project Zero。
- 投诉：通过品牌注册后台提交侵权报告，附 ASIN/链接、侵权类型（商标/专利/版权/其他）、证据。
- Test Buy：可购买侵权商品取证后向平台投诉并用于后续法律行动。

### 未注册品牌
- 通过 Amazon 知识产权投诉通道提交：身份、权属证明、侵权链接、初步证据。
- 注意 Amazon 对"合格通知"要求严格，材料不全可能被驳回。

## 二、eBay（VeRO 计划）

- 入口：eBay VeRO（Verified Rights Owner）计划。
- 材料：产权所有人身份/账户、权属证明（商标注册证/专利/版权登记）、侵权 listing 链接、侵权说明。
- 处理：平台核实后移除侵权 listing；卖家可反通知。

## 三、AliExpress / 速卖通

- 入口：全球速卖通知识产权投诉系统。
- 材料：身份验证、权属证明、侵权商品链接、初步证据。
- 处理：审核后下架/处罚店铺；卖家可申诉。

## 四、TikTok Shop（抖音电商国际版）

- 入口：TikTok Shop 商家/平台知识产权举报通道。
- 覆盖：商品、直播、短视频中的商标/版权/专利侵权。
- 材料：身份、权属、侵权内容链接、初步证据；直播侵权附录屏/截图。

## 五、Wish / Shopify / 独立站

- Wish：商户政策投诉通道，提交权属+链接。
- Shopify：DMCA 通知（版权）与商标/专利投诉（附权属证明+侵权内容 URL）。
- 独立站：先定位注册商与托管商，通过域名注册商/托管商投诉（滥用政策），必要时 UDRP 域名争议。

## 六、通用四要素（跨境同样适用）

1. 权利人真实身份（个人证件/营业执照+授权书）。
2. 当地/国际权利证明（目标国商标注册、马德里指定、PCT 进入、版权登记）。
3. 侵权内容信息（商品链接/ASIN/listing、店铺、截图）。
4. 初步侵权证据（比对说明、购买取证、公证/存证）。

## 七、申诉与反通知

- 卖家反通知（声明不侵权/有授权）后，权利人需评估并决定维持或撤销；恶意投诉可能被平台处罚。
- 平台下架不等于法律确权，保留证据并记录时间线，为后续 ITC/诉讼提供"持续侵权"证明。

## 八、与境内协同

- 同一侵权人在境内（淘宝/拼多多/抖音）与境外（亚马逊等）同时销售的，境内境外同步投诉+行政+诉讼，形成全渠道打击。
