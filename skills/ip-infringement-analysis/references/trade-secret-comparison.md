# 商业秘密侵权比对规则

## 一、比对基础
- 商业秘密构成三要件：**秘密性**（不为公众所知悉）、**价值性**（能带来商业价值）、**保密性**（权利人已采取合理保密措施）。
- 权利基础材料：密点分解清单、保密协议/制度、涉密人员范围、载体与访问记录。

## 二、侵权判定框架

### 1. 密点对应比对
- 把主张的商业秘密分解为若干**密点**（技术信息：配方、工艺、图纸、源代码；经营信息：客户名单、报价策略、招投标信息等）。
- 对每个密点逐一比对被控信息，判断是否**相同或实质相同**。
- 客户名单类：需证明是"深度客户信息"（交易习惯、需求偏好、价格底线等），简单公开信息（公开名录上的名称）不构成商业秘密。

### 2. 侵权行为类型（反不正当竞争法列举）
- 以不正当手段获取（盗窃、贿赂、欺诈、胁迫、电子侵入等）。
- 披露、使用或允许他人使用以不正当手段获取的商业秘密。
- 违反保密义务/权利人有关保守商业秘密的要求，披露、使用或允许他人使用。
- 教唆、引诱、帮助他人实施前述行为。
- 第三人明知或应知前述违法行为，仍获取、披露、使用或允许他人使用。

### 3. 接触 + 实质相同 + 无合法来源（推定规则）
- 权利人的员工/前员工/合作方在职务或合作期间接触过商业秘密（接触证据：劳动合同、权限记录、项目往来）。
- 被控信息与密点实质相同。
- 被控方无法证明合法来源（独立研发、反向工程、合法受让）→ 可推定侵权。

### 4. 常见被告抗辩
| 抗辩 | 要点 |
|---|---|
| 不构成秘密 | 已公开/易获得/未采取合理保密措施 |
| 独立研发 | 有独立研发记录、时间线证据 |
| 反向工程 | 从公开渠道合法取得产品并反向分析（不得违反合同约定） |
| 合法受让/许可 | 有授权协议 |
| 未接触 | 无接触可能或接触范围不含该密点 |
| 已过时效 | 知道或应当知道侵权之日起3年内主张 |

## 三、结论表述
给出"构成/不构成/存疑"结论 + 密点比对表 + 三要件成立性评估 + 抗辩评估 + 所需补充证据。
