# 执行流程与强制措施要点

## 一、申请执行前核查

- 生效时间：判决书送达后 15 日上诉期届满未上诉生效；二审判决送达即生效。
- 履行期：按判决确定的履行期限届满后即可申请。
- 期间：申请执行时效 **2 年**，中断/中止情形按民诉法。
- 执行管辖：第一审法院或被执行人财产所在地同级法院。

## 二、申请材料

1. 执行申请书：申请人与被执行人信息、执行依据案号、请求事项（金钱给付数额/行为义务）、财产线索。
2. 生效法律文书及生效证明。
3. 申请执行人身份证明（个人身份证/营业执照+法定代表人证明）。
4. 委托代理授权书（如有）。
5. 财产线索清单：账户、不动产、车辆、股权、应收款、平台店铺资金、许可费收益等。

## 三、执行措施速查

| 措施 | 说明 |
|---|---|
| 网络查控 | 法院总对总查控银行、不动产、车辆、证券、网络资金 |
| 冻结/划拨 | 冻结银行账户、扣划存款 |
| 查封/扣押/拍卖 | 查封不动产、扣押动产、评估拍卖变卖 |
| 扣留提取收入 | 被执行人工资、租金、许可费等收入 |
| 纳入失信名单 | 有履行能力而拒不履行/违反报告财产令等 |
| 限制高消费 | 限高令：不得乘坐飞机高铁、高消费等 |
| 罚款/拘留 | 拒不报告财产、妨害执行等 |
| 拒不执行判决裁定罪 | 有能力执行而拒不执行、情节严重，可追究刑事责任 |

## 四、拒不执行与财产转移应对

- 收到法院报告财产令后被执行人应如实报告；拒不报告/虚假报告 → 罚款、拘留。
- 转移、隐匿、变卖财产 → 申请法院调查、追究妨害执行责任；符合拒不执行判决、裁定罪要件的移送公安/由法院移送追诉。
- 被执行人无可供执行财产 → 终本（终结本次执行），保留申请恢复执行权；发现财产后随时可申请恢复。

## 五、执行异议与救济

- 案外人异议：案外人对执行标的主张权利，15 日内提出，法院审查或引导执行异议之诉。
- 执行行为异议：当事人对执行行为（如超标的查封）不服，可向执行法院提出异议、申请复议。
- 执行监督与检察监督：必要时向上一级法院或检察院申请监督。

## 六、行政/海关执行的衔接

- 行政裁决/处罚决定：行政机关可申请法院强制执行或依法自行执行；海关没收侵权货物并处罚款。
- 涉外执行：被执行人境外财产的，依海牙判决承认执行、双边司法协助等途径推进（配合跨境技能）。

## 七、复发监测

- 再犯识别：同主体/关联主体新店铺、新链接、改头换面产品。
- 再犯后果：重复侵权可作为"情节严重"主张惩罚性赔偿；行政/刑事再启动。
- 监测工具：衔接 S0 监测台账与 S1 线索发现，形成"维权—执行—监测—再维权"闭环。
