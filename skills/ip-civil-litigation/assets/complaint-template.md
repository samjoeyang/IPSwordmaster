# 知识产权民事起诉状模板

**民事起诉状**

原告：[姓名/名称]，[性别/主体类型]，[身份证号/统一社会信用代码]，住所地：[____]，联系电话：[____]。
法定代表人（单位）：[____]。
委托诉讼代理人：[____]（如有，附授权委托书）。

被告：[姓名/名称]，[主体类型]，住所地：[____]，联系电话：[____]。
法定代表人（单位）：[____]。

诉讼请求：
1. 判令被告立即停止侵犯原告[商标权/专利权/著作权/商业秘密]的行为（包括但不限于停止生产、销售、许诺销售、进口、传播、使用[被控对象]）；
2. 判令被告赔偿原告经济损失及为维权支出的合理费用共计人民币[____]元（其中经济损失[____]元，合理开支[____]元）；
3. 判令被告承担本案全部诉讼费用；
4. （可选）判令被告[销毁侵权产品及专用模具/刊登声明消除影响/承担惩罚性赔偿____元]。

事实与理由：
一、原告系[权利类型]的权利人。原告于[____]年[____]月[____]日取得[权利名称/注册号/专利号/登记号]，权利有效期至[____]，现处于有效状态。
二、被告未经原告许可，实施了下列行为：[被控行为描述：生产/销售/许诺销售/传播[被控对象]，链接/地点[____]，销量/价格[____]]，该行为落入原告权利保护范围，具体比对见证据[____]。
三、被告行为造成原告损失[____]（[计算口径：实际损失/侵权获利/许可费倍数/法定赔偿]），并支出公证费[____]元、律师费[____]元、购买费[____]元等合理费用。
四、（如主张惩罚性赔偿）被告系故意侵权且情节严重，依法应承担惩罚性赔偿责任。

综上，依据《中华人民共和国[商标法/专利法/著作权法/反不正当竞争法]》第[____]条、《中华人民共和国民事诉讼法》第[____]条，特向贵院提起诉讼，请依法裁判。
