# 商标侵权比对规则

## 一、比对基础
- 以**注册商标**的核准图样与核定商品/服务类别为准。
- 被控使用行为：在商品/服务、包装、广告、网络推广、店铺名称、域名等上的使用。

## 二、侵权判定框架

### 1. 相同商标 + 相同/类似商品
- 商标相同（视觉上无差异）+ 用于相同商品 → 直接侵权（假冒），无需混淆要件。
- 商标相同 + 用于类似商品 → 需判断混淆可能性（推定混淆，一般认定）。

### 2. 近似商标 + 相同/类似商品
- 商标近似判断：以相关公众的一般注意力为标准，**隔离观察**、整体比对、要部比对，考虑音、形、义。
- 商品类似判断：功能用途、生产部门、销售渠道、消费对象等关联程度。
- 结论需落在"是否容易导致相关公众混淆/误认"。

### 3. 驰名商标（跨类保护）
- 主张驰名商标保护的，需提交驰名证据（宣传持续时间、地域、程度、受保护记录、市场声誉等）。
- 已认定驰名的，可对不相同/不类似商品上的复制摹仿主张保护（个案认定原则）。

### 4. 其他侵权行为
- 销售侵犯注册商标专用权商品（含未经授权销售正品但篡改/撕标）。
- 伪造、擅自制造注册商标标识或销售伪造标识。
- 反向假冒（更换注册商标后投入市场）。
- 为侵权提供仓储、运输、邮寄、印制、隐匿、经营场所、网络平台等便利。

## 三、被告抗辩
| 抗辩 | 要点 |
|---|---|
| 商标不近似/商品不类似 | 隔离比对不构成近似；类别不类似且无关联 |
| 正当使用/描述性使用 | 使用自己名称字号、描述性词汇、指示性使用（兼容/适用于X）需规范使用 |
| 在先使用 | 在商标注册前已连续使用并有一定影响，可在原范围内继续使用（可附加区别标识） |
| 合法来源 | 销售者不知情且能证明合法来源，免除赔偿责任 |
| 三年未使用 | 对"撤三"程序中未使用部分，权利人无法主张赔偿（需证明实际使用） |
| 权利用尽 | 正品平行进口场景下的合理使用（视司法口径） |
| 恶意抢注/权利滥用 | 原告权利基础存在瑕疵（如抢注他人先用商标） |
