# 专利侵权比对规则

## 一、发明/实用新型专利

### 1. 比对基础
- 以**授权公告的权利要求书**为准（以最新生效文本为限），说明书及附图用于解释权利要求。
- 被控侵权技术方案与权利要求记载的技术特征**逐项比对**。

### 2. 全面覆盖原则（字面侵权）
被控技术方案包含与权利要求记载的**全部技术特征相同**的技术特征，即落入保护范围。
任一技术特征未被覆盖（不同且不等同）则不构成字面侵权，进入等同判断。

### 3. 等同原则
对字面不同但"以基本相同的手段，实现基本相同的功能，达到基本相同的效果，且本领域技术人员无需创造性劳动即可联想到"的技术特征，仍可认定等同侵权。
等同判断限缩情形：
- 被控技术方案属于**现有技术**的，不构成侵权（现有技术抗辩）。
- 被控技术方案属于**自由公知技术**或明显借鉴了自由公知技术的，不构成侵权。
- 禁止反悔：专利权人在授权/确权程序中放弃的内容不得再通过等同主张。

### 4. 常见被告抗辩
| 抗辩 | 要点 |
|---|---|
| 现有技术/现有设计 | 被控方案在申请日前已公开（抵触申请/公知常识不构成侵权） |
| 先用权 | 申请日前已制造相同产品/使用相同方法，并在原有范围内继续 |
| 合法来源 | 销售者/使用者能证明合法取得（免除赔偿责任，仍需停止侵权） |
| 权利用尽 | 专利产品或依专利方法直接获得的产品首次售出后，后续使用/许诺销售/销售不侵权 |
| 不视为侵权 | 临时过境交通工具、专为科学研究和实验使用、药品/医疗器械行政审批提供信息 |
| 现有技术（等同阶段） | 等同比对阶段可将现有技术组合作为抗辩 |

### 5. 结论表述
结论必须给出：落入/不落入/存疑 + 依据的特征对比表。

## 二、外观设计专利

### 1. 比对对象与基础
- 以授权公告的**外观设计图片或照片**为准，简要说明用于解释。
- 与**被控侵权产品**的同类或近似类别产品的外观做整体比对。

### 2. 判断标准
- **整体观察、综合判断**：以一般消费者的知识水平和认知能力，判断是否构成相同或近似。
- 相同：外观设计与授权设计在整体视觉效果上无差异。
- 近似：整体视觉效果无实质性差异。
- 不考虑：产品内部结构、功能决定的设计、惯常设计、授权外观与现有设计区别点之外的设计（区别点权重更高）。

### 3. 常见抗辩
- 现有设计抗辩。
- 功能限定（某特征由功能唯一决定，不纳入比对）。
- 惯常设计（某部分属于该类产品常见设计，弱化）。
- 合法来源（销售者免责）。

### 4. 结论表述
给出"相同/近似/不近似"结论 + 整体视觉对比要点（区别点与相同点列表）。
