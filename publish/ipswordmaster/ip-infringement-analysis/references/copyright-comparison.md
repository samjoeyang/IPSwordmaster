# 著作权侵权比对规则

## 一、比对基础
- 著作权保护的是**作品的表达**，不保护思想、工艺、操作方法、数学概念等。
- 权利人需先证明：对作品的著作权（登记证书/底稿/首发记录）与作品的独创性表达。
- 被控行为通常涉及：复制权、发行权、信息网络传播权、改编权、表演权等。

## 二、侵权判定框架

### 1. "接触 + 实质性相似"规则
- **接触**：被控方有合理可能接触过权利人作品（在先发表/公开传播/业务往来/员工流动等）。
- **实质性相似**：对被控作品与权利作品做**表达层面**比对：
  - 文字作品：结构、情节、人物设置、具体表达段落（不只比对思想主题）。
  - 美术/摄影：构图、造型、色彩、细节表达的整体观感。
  - 软件：代码级比对（源程序/目标程序），结构、顺序、组织（SSO）可辅助；考虑技术事实鉴定。
  - 视听作品：分镜、画面、台词、剪辑的实质性相同。
- 实质性相似判断排除：公有领域元素、思想层面的通用情节、有限表达（表达方式有限时不受保护）。

### 2. 合理使用边界（不侵权抗辩）
- 为个人学习研究、适当引用（注明出处）、新闻报道、教学科研、执行公务、图书馆馆藏等合理使用情形。
- 转换性使用/戏仿需个案判断。
- 网络服务提供者的"通知-删除"避风港：仅提供存储/搜索/传输等服务的平台，接到合格通知后及时删除并转通知的，可免赔偿责任。

### 3. 常见被告抗辩
| 抗辩 | 要点 |
|---|---|
| 独立创作 | 无接触+创作过程独立（碰巧相似） |
| 思想/事实不受保护 | 仅表达思想、事实、通用情节 |
| 合理使用 | 符合法定合理使用情形 |
| 实质性不相似 | 仅有整体感觉相似，具体表达不同 |
| 已过保护期 | 自然人作品作者死后第50年；法人作品首次发表后50年 |
| 授权/许可 | 有合法授权或免费许可 |

## 三、结论表述
给出"构成/不构成/存疑"结论 + 表达比对表（独创性表达 vs 被控表达）+ 接触证据评估 + 合理使用评估。
