# 各平台投诉流程要点

> 平台规则会调整，执行前以平台当期指引为准；本文件为操作框架。

## 一、通用通知要素（所有平台）

1. 权利人真实身份信息（个人：身份证；单位：营业执照 + 法定代表人/经办人身份；代理：另附授权书）。
2. 知识产权权利证明：
   - 商标：注册证（含续展记录）。
   - 专利：证书 + 年费缴纳凭证（实用新型/外观需关注是否需评价报告）。
   - 著作权：登记证书，或创作底稿/首发记录（图片类可提交原图+拍摄底稿）。
3. 涉嫌侵权商品信息：商品链接、店铺名称、商品截图（含价格、销量、评价）。
4. 初步侵权证据：侵权比对说明、实物照片、公证书/时间戳存证、购买记录。

## 二、淘天（淘宝/天猫）IPP 平台

- 入口：阿里巴巴知识产权保护平台（IPP 平台）。
- 流程：注册账号 → 验证身份信息与知识产权证明材料 → 在线提交侵权商品链接发起投诉 → 平台审核后删除链接 → 卖家可申诉 → 平台结合双方材料判断是否恢复。
- 权利人若对卖家申诉不认可，可申请平台小二介入。
- 要点：投诉时选择正确站点（淘宝/天猫/国际站等）与权利类型；图片盗图类投诉建议附官网/旗舰店截图（含地址栏）。

## 三、京东

- 入口：京东知识产权维权系统（帮助中心维权入口）。
- 首次投诉需先"备份权属信息"：填写权属信息并提供证明文件。
- 著作权侵权投诉可择一提交：登记证书 / 原图、原视频拍摄底稿等证明材料 / 其他可证明权属的凭证。
- 流程：填写投诉信息（商品、权利、理由、证据）→ 平台审核 → 删除/下架 → 卖家申诉 → 双方举证。

## 四、拼多多

- 入口：拼多多知识产权保护平台（IPP 平台）。
- 流程：创建投诉账号 → 上传身份证明材料 → 上传知识产权材料 → 提供侵权投诉信息（商标/专利/著作权）→ 平台处理及反馈。
- 材料：营业执照（单位）/身份证明（个人）、维权授权书及授权人资质（如有）、权利证书；按权利类型提交对应证据。
- 平台对举报处理情况依法公示。

## 五、抖音/快手等内容电商

- 各平台设知产投诉/侵权举报入口，流程同通用四要素。
- 涉及直播/短视频侵权：投诉时附直播间 ID、视频链接、录屏证据。

## 六、申诉应对

| 卖家申诉类型 | 应对 |
|---|---|
| 主张有授权 | 要求平台核实授权链；权利人核验授权书真伪并答复 |
| 主张不侵权（不近似/不落入） | 提交比对说明与证据，申请平台介入 |
| 主张权利用尽/平行进口 | 结合商品来源证据个案判断 |
| 反通知（声明投诉错误） | 评估后决定维持/撤销，避免恶意投诉认定 |

## 七、时间与升级

- 平台处理一般数个工作日内；催办与留痕。
- 卖家"换店重犯/反复上架"：记录台账，升级行政举报或诉讼，并把平台"收到合格通知后未及时处置"作为追责平台责任的证据。
