## 二、知识产权海关保护备案

依据《知识产权海关保护条例》及海关总署实施办法：

1. **备案主体**：知识产权权利人（或经授权的利害关系人）。
2. **备案平台**：海关总署知识产权海关保护备案系统，提交权利人主体信息、权利证明（商标注册证/专利证书/著作权登记）、合法使用人信息（可选）。
3. **备案后效果（依职权保护）**：海关发现进出口货物涉嫌侵犯备案知识产权的，中止放行并以《确认货物知识产权状况通知书》书面告知权利人；权利人自通知送达之日起 **3 个工作日内** 提出扣留申请并提供担保的，海关扣留嫌疑货物；逾期未申请或未提供担保的，海关恢复放行。
4. **担保**：需提供不超过货物等值金额的担保（可申请总担保以简化多次扣留）。
5. **未备案情形（依申请保护）**：权利人发现侵权嫌疑货物即将进出口的，可直接向进出境地海关提交申请书+权利证明+明显侵权证据+担保，申请扣留。

## 三、监测台账模板

| 字段 | 说明 |
|---|---|
| 记录编号 | 唯一编号 |
| 发现日期 | YYYY-MM-DD |
| 渠道 | 平台/市场/展会/海关/域名 |
| 关键词/检索方式 | 本次检索所用关键词或图片 |
| 疑似侵权链接/主体 | URL 或主体名称 |
| 初步判断 | 疑似侵犯的权利类型 |
| 证据留存 | 截图/录屏/链接存档位置 |
| 处理状态 | 待评估/已提交比对/已投诉/已诉讼 |
