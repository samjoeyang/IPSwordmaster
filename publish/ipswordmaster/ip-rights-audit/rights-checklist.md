# 权利核查要点清单

> 逐项核对时区分：已核验（有凭证）/待补证（用户未提供）/不适用。

## 一、专利权

| 核查项 | 要点 |
|---|---|
| 类型与期限 | 发明 20 年、实用新型 10 年、外观设计 15 年，均自申请日起算 |
| 年费 | 每年度缴费凭证；滞纳期与恢复期规则；欠费可能导致权利终止 |
| 无效风险 | 是否已进入/可能进入无效宣告程序；权利要求是否稳定（对比现有技术初步判断） |
| 权利要求 | 以最新生效文本为准；独立权利要求保护范围为核心 |
| 权属 | 专利权人、共有权人、转让/质押登记状态、职务发明约定 |

## 二、商标权

| 核查项 | 要点 |
|---|---|
| 有效期 | 注册有效期 10 年；是否办理续展 |
| 撤三风险 | 连续三年未使用可能被撤销；备好使用证据（销售记录、广告、发票） |
| 类别 | 核定商品/服务类别；对方商品是否落入核定范围 |
| 近似族 | 同主体近似商标的注册情况（维权时主张"商标包"更稳） |
| 许可/备案 | 是否许可他人使用、是否已备案；许可范围对维权主体资格的影响 |

## 三、著作权

| 核查项 | 要点 |
|---|---|
| 权属证据 | 登记证书、创作底稿、首发记录（时间戳/网页存档）、源代码/设计源文件 |
| 作品类型 | 文字、美术、摄影、视听、软件等；不同作品类型侵权比对规则不同 |
| 权利内容 | 复制、发行、信息网络传播、改编、展览等；明确被侵犯的是哪几项 |
| 职务/委托 | 职务作品、委托作品权属约定；转让/授权合同是否齐备 |

## 四、商业秘密

| 核查项 | 要点 |
|---|---|
| 秘密性 | 不为公众所知悉；已公开部分不构成秘密点 |
| 价值性 | 能带来商业价值/竞争优势 |
| 保密性 | 合理保密措施：保密协议、涉密人员管理、权限控制、保密标识、保密制度 |
| 密点分解 | 把商业秘密拆成可主张的"密点"清单，比对时逐点对应 |
| 来源 | 明确技术/经营信息的载体、接触人员范围（涉密人员名单） |
