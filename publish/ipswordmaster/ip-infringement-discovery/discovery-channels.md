# 发现渠道、主体溯源与线索分级

## 一、渠道检索方法

### 电商平台
- 关键词组合：品牌名+品类词、品牌名+仿冒常见词（高仿/同款/复刻/1:1/专柜代购）、近似词（拼音、谐音、拆字）。
- 图片检索：以正品图/权利图反向搜同款。
- 排序关注：销量降序、价格异常低的链接、非官方店铺。
- 平台内工具：淘天 IPP 平台商品监控、拼多多知产平台举报入口可辅助定位。

### 线下与展会
- 展会：开展前查参展商名录，现场对展位拍照取证，索取名片/宣传册。
- 市场：目标批发市场、专业市场巡检，注意贴牌加工（OEM/ODM）线索。

### 社交媒体与内容平台
- 小红书/抖音/快手/微信：搜索品牌名+品类，关注种草笔记中的非官方购买渠道、直播带货。

### 海关与跨境
- 海关总署备案系统：进出口侵权风险。
- 跨境电商平台（亚马逊、eBay、AliExpress、TikTok Shop）：按站点分别检索。

### 域名
- 近似域名注册查询（品牌名+.com/.cn/.net 及易混淆拼写），用于后续域名争议。

## 二、主体溯源要点

| 层级 | 溯源内容 | 信息来源 |
|---|---|---|
| 销售终端 | 店铺/账号主体、注册地、发货地 | 平台店铺资质页、商品页、物流 |
| 批发/供货 | 是否一件代发、供货商联系方式 | 客服询问、商品详情 |
| 生产端 | 厂名厂址、包装标识、认证标志 | 产品实物、包装 |
| 出口端 | 报关主体、货代 | 跨境线索 |

## 三、线索分级标准

| 级别 | 判定条件 | 处理建议 |
|---|---|---|
| A | 证据可固定（可购买取证/公证）+ 销量或规模大 + 影响核心市场 | 优先进入比对与维权 |
| B | 证据较明确 + 规模中等 | 常规处理 |
| C | 疑似但证据不足 | 监测观察，暂不启动成本动作 |

## 四、台账模板

记录编号 / 发现日期 / 渠道 / 关键词 / 链接或位置 / 主体信息 / 价格销量 / 疑似权利类型 / 证据留存 / 级别 / 下一步动作
