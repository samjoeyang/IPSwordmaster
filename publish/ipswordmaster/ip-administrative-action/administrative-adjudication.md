# 行政裁决与行政查处要点

## 一、专利侵权纠纷行政裁决

### 请求条件
1. 请求人是专利权人或者利害关系人（含专利实施许可合同被许可人、专利权人合法继承人等）。
2. 有明确的被请求人。
3. 有明确的请求事项和具体事实、理由。
4. 属于受案管理专利工作的部门的受案和管辖范围。

### 请求材料
- 《专利侵权纠纷处理请求书》（写明请求人与被请求人信息、请求事项、事实与理由）。
- 主体资格证明：自然人身份证或其他有效证件；法人/非法人组织营业执照副本及法定代表人（主要负责人）身份证明。
- 专利证书及专利权有效证明（年费缴纳凭证/专利登记簿副本）。
- 侵权证据：被控产品实物或照片、购买凭证、比对材料（衔接 S3 证据包）。
- 委托代理的，附授权委托书。

### 程序与时限（依据《专利纠纷行政裁决和调解办法》）
1. 立案审核：办案人员提出是否立案意见，经办案处（科）室负责人审核、部门负责人审批；指定 3 名或 3 名以上单数执法人员处理。
2. 受理通知：自收到请求书之日起 **5 个工作日内**向请求人送达《专利侵权纠纷处理请求受理通知书》。
3. 答辩通知：自立案之日起 **5 个工作日内**向被请求人送达《答辩通知书》、请求书及证据副本，要求答辩。
4. 审理：书面审理或口头审理；当事人对自己主张有提供证据的责任。
5. 裁决：作出是否侵权的行政裁决；认定侵权的，责令停止侵权行为。

### 调查取证
当事人及其代理人因客观原因不能自行收集证据的，可申请管理专利工作的部门签发**调查通知书**，持调查通知书向有关单位/个人调查收集不涉及国家秘密、商业秘密或个人民事隐私的证据。

### 后续衔接
- 不服裁决：可依法申请行政复议或提起行政诉讼。
- 对方拒不履行：申请人民法院强制执行。
- 索赔：行政裁决确认侵权后，另行提起民事诉讼主张赔偿（裁决认定可作为证据）。

## 二、商标侵权行政查处

- 受理机关：侵权行为地县级以上市场监督管理部门。
- 举报材料：投诉/举报书、主体资格、商标注册证、侵权线索（店铺/市场/生产地址）、侵权证据。
- 执法措施：现场检查、询问调查、查封扣押涉嫌侵权商品/工具、抽样取证。
- 处理：认定侵权的，责令立即停止侵权行为，没收、销毁侵权商品和主要用于制造侵权商品、伪造注册商标标识的工具，可处罚款；涉嫌犯罪的移送公安。

## 三、著作权行政处罚

- 受理机关：版权局/文化市场综合执法部门。
- 依据《著作权行政处罚实施办法》，办案人员可采取：抽样取证；对涉嫌侵权制品、安装存储侵权制品的设备、网站网页、服务器等先行登记保存。
- 处理：责令停止侵权行为、警告、没收违法所得、没收销毁侵权复制品、罚款；构成犯罪的移送司法。

## 四、商业秘密/不正当竞争查处

- 受理机关：市场监督管理部门。
- 举报材料需围绕三要件（秘密性、价值性、保密性）提供权利外观证据 + 侵权行为与结果证据（可公证、时间戳、区块链取证防止灭失）。
- 处理：责令停止违法行为、没收违法所得、罚款；情节严重从重。
