# 取证方式操作要点

## 一、线上证据固定

### 通用流程（公证/存证均适用）
1. 清洁环境：关闭无关程序，记录操作设备信息（系统时间、网络环境）。
2. 全程操作可视化：从入口页开始逐步录屏/截图，包含地址栏完整 URL。
3. 关键页面：商品页（标题、图片、价格、销量、评价）、店铺页（主体信息）、购买流程、物流与收货。
4. 保存证据：完整录屏文件、逐页截图、页面 HTML 源码、操作日志。

### 公证取证
- 向公证处申请网页保全/购买行为保全公证。
- 公证员监督操作或由公证处指定设备操作。
- 产出：公证书（核心证明力，诉讼基本必须）。

### 可信时间戳/区块链存证
- 使用合法存证平台（如联合信任时间戳、公证处区块链存证平台等）。
- 对网页进行完整取证：打开首页 → 逐页浏览 → 对目标页面点击"存证"。
- 生成存证证书/哈希校验值，妥善保存原始文件（哈希变化则无法验证）。
- 区块链存证在诉讼中可提交存证凭证+验证报告，法院可结合其他证据认定。

### 自行取证（辅助）
- 仅截图+录屏，记录时间与来源；明确其证明力弱，建议叠加公证/存证。

## 二、线下证据固定

| 场景 | 操作 | 关键证据 |
|---|---|---|
| 市场购买 | 现场购买，索要发票/收据/名片，拍照录视频（含店铺门头、货架、交易过程） | 实物、票据、现场影像 |
| 展会 | 展位拍照、索取宣传册/名片、交谈录音（注意合法性） | 展位影像、宣传册、名片 |
| 生产端 | 厂名厂址、包装标识拍摄 | 包装、标识照片 |
| 委托公证 | 公证员随行公证购买全过程 | 公证书 |

## 三、技术/商业秘密类证据

- 源代码/文档：从开发环境导出，计算 SHA-256 哈希，封存原件或公证。
- 系统数据：日志、访问记录、权限记录，注意提取程序合规（防止破坏数据完整性）。
- 服务器/电子设备：可申请法院证据保全或公证处保全，必要时委托司法鉴定机构做电子数据鉴定。

## 四、诉前/诉中证据保全

- 适用：证据可能灭失或以后难以取得（网页随时下架、货物即将转移、服务器数据易篡改）。
- 法律依据：《民事诉讼法》诉前/诉中证据保全规定；商标法、专利法、著作权法均有"诉前申请保全证据"条款。
- 申请材料：保全申请书、权利证明、侵权初步证据、说明证据灭失风险的充分理由、担保（按法院要求）。
- 保全措施：查封、扣押、拍照、复制、查封服务器、提取电子数据等。
- 时限注意：诉前保全后应在法定期限内起诉，否则法院解除保全。

## 五、损害证据

| 证据 | 来源 |
|---|---|
| 权利人销售下滑 | 财务数据、电商后台销售记录、客户流失记录 |
| 侵权获利 | 侵权店铺销量、评价数（保守估算）、价格与成本、广告投放记录 |
| 许可费 | 已有许可合同、行业许可费率 |
| 维权开支 | 公证费发票、律师费合同与发票、购买侵权产品费用、差旅费 |

## 六、证据链结构

```
权利证据（S0） → 侵权证据（比对对象+侵权事实） → 损害证据（损失/获利/开支）
      ↓                ↓                          ↓
主体同一性（侵权人=被告）  时间连续性（侵权持续期间）   数额可计算（口径一致）
```
