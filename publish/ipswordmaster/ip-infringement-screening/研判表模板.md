# 侵权线索研判表（输出模板 v0.2）

> 本模板字段设计对齐「侵权链接登记台账」的登记体系，研判结果可直接回填台账，无需二次转换。
> 输出时严格使用下表字段，缺失填「待补」，不得省略列。
> 线索超过 30 条时：先输出等级分布摘要，再按 P0 → P3 分组输出明细。

## 三、字段填写规范

**渠道类型**（决定处置难度和优先级）：
- 站内电商：平台商品链接，投诉通道成熟，成功率最高
- 站外社交：种草帖、社群引流，投诉通道较弱，常需先固定内容再处理
- 二手闲置：需重点排查权利用尽（是否为正品转卖）
- 源头批发：价值最高（打源头），但主体核查和取证难度也最高
- 独立站/跨境：投诉通道不稳定，常需域名/支付/托管多层施压
- 线下档口：需行政投诉或诉讼路径，平台投诉不适用

**白名单判定**：先比对授权白名单（官方旗舰店、官方直营、一级授权、经销/分销、授权专卖）。
命中白名单即**排除，不进入研判**；白名单外才标记「疑似」继续研判。
无白名单数据时填「未核对」并在待补材料提示先维护白名单。

**价格异常 / 销量异常**（重要风险信号，需在判定依据中体现）：
- 价格显著低于正品市场价（如低于 5 折）→ 假冒嫌疑显著上升
- 销量异常高但价格极低 → 规模化侵权，优先级上调
- 价格正常且销量小 → 可能是零散窜货，需先排查权利用尽

**近似度**：
- 高：标识高度近似或实质性相同，且用于相同或类似商品
- 中：存在一定差异但整体视觉或呼叫效果接近
- 低：差异明显，或商品类别/使用场景差异大

**判定依据（最关键，不得空缺）**：必须写清
① 比对了哪些要素（文字/图形/颜色组合/整体装潢）
② 相同点是什么
③ 差异点是什么
④ 为何认定达到或不达到近似程度
⑤ 是否参考了价格/销量异常信号

**抗辩排查**：逐条过一遍，确认无抗辩才填「无」。发现抗辩应下调等级并说明。

**证据强度**（**独立维度，不参与风险分级**）：
- 强：已固证（时间戳/区块链/公证）+ 可锁定主体 + 链接稳定
- 中：部分固证或主体待核
- 弱：仅截图无固证、链接易失效、主体不明

**风险等级**（只评估**侵权成立可能性 + 处置价值**，与证据强度无关）：
- P0 侵权成立可能性高、有效抗辩已排除、处置价值显著（规模化/典型/可批量）→ 优先处置，证据弱则先固证
- P1 成立可能性较高，但有待核实项（主图/授权链/主体），或处置价值一般 → 补证核实后再投诉
- P2 边界模糊、法律上存争议（描述性使用、比较性使用、未直接使用标识）→ 不宜直接投诉，先发函或深挖
- P3 不构成侵权、命中白名单、存在有效抗辩，或维权成本高于收益 → 不处置，归档观察

> 交叉读法：P0 + 弱证据 = 「先固证再投诉」，最优先补证；P1 + 弱证据 = 「补证后再判」；
> P2 / P3 无论证据强弱，都不建议立即投诉。

## 四、行动建议摘要（表后必附）

1. 本批各等级分布与整体判断
2. 建议优先处理的 3–5 条，各一句话理由
3. 需要补充的材料清单（固证/主体核查/白名单维护）
4. **明确提示：哪些属于 P2/P3，不建议立即投诉，避免误伤和恶意投诉风险**

## 五、结尾固定声明

> 本研判表为维权工作内部参考，不构成法律意见，不得直接作为对外法律文书或诉讼依据使用。
> 所有结论需经具备执业资格的专业人员复核后，方可用于平台投诉、律师函发送或诉讼等对外法律行动。
