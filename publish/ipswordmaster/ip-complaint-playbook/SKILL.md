# 平台投诉方案

> ## 使用边界（每次输出都必须遵守）
>
> 1. 本技能输出为维权工作的**内部执行方案，不构成法律意见**。对外提交前须经具备执业资格的专业人员复核。
> 2. **禁止承诺投诉结果。** 用「通过可能性较高」「该平台此类案由通常需补强 X」，禁止说「一定能下架」。
> 3. 平台规则变动频繁。涉及入口地址、材料清单、审核周期的内容，**必须以平台最新公告为准**，本技能给出的是方法框架与待核实的经验值。
> 4. 客户名称、案件主体、授权链、白名单属保密信息，不得写入对外提交材料以外的任何场合，不得跨客户复用。

---

## 铁律一：投诉即惊动对方，先固证再动手

平台投诉一旦提交，对方会收到通知，随即可能**下架、改页、关店、换链接**。证据灭失后无法补做。

因此执行前必须逐条确认：

| 前置检查 | 不通过时 |
|---|---|
| 线索已完成固证（截图带 URL + 时间，或时间戳/公证） | **停止**，转「取证固证」先补证 |
| 已核对白名单，确认不在授权体系内 | **停止**，转渠道治理或授权核查 |
| 权利基础有效（商标在有效期内、已续展、类别覆盖） | **停止**，先补权利证明 |
| 投诉主体与权利人关系清晰，授权链完整可出示 | **停止**，先补授权委托书 |
| 该链接此前未用同一权利重复提交过 | 合并，不重复提交 |

**没有固证就提交投诉，是维权工作里最贵的一个错误。**

---

## 铁律二：投诉不是"告他"，是"让平台相信该删"

平台审核员不看法律关系是否成立，只看三件事：

1. **你有没有这个权利**（权属证明）
2. **他是不是真的在侵犯这个权利**（对比说明）
3. **删了他会不会有风险**（有无合法来源/授权/合理使用可能）

绝大多数驳回不是因为"不侵权"，而是因为**第 2 点没讲清楚**。对比说明的质量决定通过率。

## 工作流程

### 第 1 步：前置检查（见铁律一）
逐条过表，任何一条不通过就停下来，明确告诉用户缺什么、去哪补。

### 第 2 步：确定投诉通道
按平台查 `references/平台投诉规则矩阵.md`。

要点：
- 阿里系（淘宝/天猫/1688/闲鱼）统一走**阿里巴巴知识产权保护平台（IPP）**，一次认证覆盖多站
- 微信生态走**微信品牌维权平台**，与公众号/小程序/视频号小店分属不同入口
- 抖音/快手/拼多多/京东各有独立知识产权保护平台，需分别注册认证
- 小红书、唯品会入口相对分散，通常站内举报 + 邮件并行
- **独立站没有平台通道**，只能打域名商/托管商/支付渠道（见矩阵）
- **跨境平台**走各自的品牌备案体系，未备案几乎无法投诉

### 第 3 步：选案由
案由不是"越重越好"，而是**匹配度越高越好**。优先级：

| 案由 | 适用 | 优势 | 风险 |
|---|---|---|---|
| 商标侵权 | 标题/主图/详情页突出使用相同或近似标识 | 判定标准清晰，通过率最高 | 需类别覆盖；被提描述性使用抗辩 |
| 著作权侵权 | 盗用主图、详情图、文案、包装设计 | 无需类别比对，盗图几乎必过 | 需证明权属与创作在先 |
| 专利权 | 外观/实用新型/发明 | 力度最强 | **需专利权评价报告**，门槛高、周期长 |
| 不正当竞争 | 仿冒包装装潢、混淆性店名 | 可补商标类别缺口 | 需知名度证据，平台侧认定弱 |

**一链接能同时主张多个案由时，按上表顺序优先主张第一个**，不要一次全押——驳回会污染投诉记录。

### 第 4 步：备材料清单
通用四件套，缺一不可：

1. **主体证明**：营业执照 / 身份证
2. **权利证明**：商标注册证（含续展页）、作品登记证书、专利证书 + 评价报告
3. **授权链**：权利人 → 各级授权 → 我方，每一级都要有盖章的授权委托书，且**授权事项必须明确包含"代为投诉/维权"**
4. **侵权证据**：带 URL 和时间的页面截图、固证凭证编号、正品与被控侵权品对比图

> **授权链断链是最常见的硬伤。** 品牌方授权给 A 公司，A 再委托我方，中间缺任何一份文件都会被驳。

### 第 5 步：写侵权对比说明（决定通过率的关键）
用三段式，不要写"跟我的一样"：

**① 权利基础** — 我方在第 X 类享有「XXX」注册商标专用权，商标证号 XXX，有效期至 XXXX 年，核定商品含【具体商品】。

**② 侵权点比对** — 被控链接在【商品标题/主图/详情页/店招】的【具体位置】使用了【具体标识】。该标识与我方商标在【字形/读音/含义/整体视觉效果】上构成【相同/高度近似】。

**③ 混淆论证** — 被控商品与我方核定商品属【相同/类似】商品，且售价【明显低于/接近】正品（正品 XX 元，被控 XX 元），相关公众施以一般注意力，容易产生【来源混淆/关联关系误认】。

> 常见错误：只写②不写③。平台审核员看不到"为什么这会混淆"，就直接驳回。

### 第 6 步：排提交节奏
批量投诉**不能一次性全投**：

- 同账号单日提交量控制在平台容忍范围内，**分批次、分日期**提交
- 同一链接同一权利**只投一次**，重复提交会被判定滥用，掉账号权重
- 先投 3–5 条**最典型的高置信样本**试水，看通过率和驳回理由，再决定后续批次怎么调整话术
- 每条提交后**记录受理编号**，回填台账

### 第 7 步：跟踪与回填
处置状态按台账字典标注：待投诉 / 已提交投诉 / 处理中 / 申诉中 / 已下架 / 已发函 / 诉讼中 / 暂不处置 / 失败。

每条投诉记录：提交时间、平台、案由、受理编号、当前状态、回执截图编号。

## 驳回后的补救

查 `references/驳回原因与补救策略.md` 定位原因。核心原则：

- **材料性问题**（权属过期、授权断链、材料不清）→ 补齐后重新提交，**这是最容易救的**
- **认定性问题**（不构成近似、描述性使用、权利用尽）→ 不要硬投第二次，改走发函或诉讼
- **链接已失效** → 直接归档，回填"已下架"，不占用投诉额度

**同一链接被驳回两次以上，停止平台路径。** 继续投只会损害账号权重，应升级为律师函或行政/司法路径。

## 申诉应对（对方申诉后）

对方申诉常见四类理由与应对：

| 对方主张 | 核验要点 | 应对 |
|---|---|---|
| 有授权 | 授权书真伪、授权期限、授权范围是否含该平台 | 真授权→撤诉并转渠道治理；假授权→提交伪造证据说明 |
| 在先使用 | 使用时间是否早于我方商标申请日 | 属实→该平台撤诉，评估是否继续 |
| 自有商标 | 其商标类别、申请日、是否构成冲突 | 提交异议/无效线索，但**不在投诉环节纠缠** |
| 货源合法（正规发票） | 发票数量与销量是否匹配、供货方是否在授权链内 | 匹配→多为窜货，转渠道治理；不匹配→发票存疑，要求平台核验 |

**"是不是侵权"和"是不是窜货"是两件事。** 窜货不构成侵权，用侵权投诉打窜货必然失败，应走渠道处罚。

## 输出规范

1. 输出一份**投诉方案书**，格式见 `templates/投诉方案书模板.md`
2. 目标清单逐条编号，编号规则沿用研判阶段的线索编号（如 `TB-001`）
3. 每条必须给出：平台 / 通道 / 案由 / 材料清单 / 对比说明草稿 / 预期通过可能性 / 备选路径
4. 材料清单用勾选框，缺项的明确标注「待补：XXX」
5. 全部结论标注为**内部研判参考**，文末附免责声明
6. 结尾给出**台账回填对照表**（处置状态、受理编号、提交时间）

---

## 注意事项

- **不承诺结果**，不写"保证下架"
- **不编造平台入口地址、审核周期、通过率**；不确定的一律标注「待核实」
- 平台规则会变，每次投诉前**重新核实入口与材料要求**
- 客户信息严格隔离，不同客户的材料不得混用
- 涉及 P2 级（边界模糊）的线索，**不进入本流程**，先走发函或深度研判
