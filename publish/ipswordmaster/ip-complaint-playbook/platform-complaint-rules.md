## 阿里系：淘宝 / 天猫 / 1688 / 闲鱼

**通道**：阿里巴巴知识产权保护平台（IPP）

**特点**：
- 一次账号认证 + 权利备案，覆盖淘宝、天猫、1688、闲鱼、阿里国际站
- 投诉类型可选：商标、著作权、专利、其他（不正当竞争归"其他"）
- 权利需**先在平台备案**才能发起投诉，备案本身需要 1–3 个工作日
- 有投诉记录与通过率沉淀，账号权重影响后续审核速度

**关键材料**：主体证明、权利证明（需在平台备案）、授权链、侵权链接、对比说明

**常见坑**：
- 权利未备案直接投诉 → 无法提交
- 商标类别与被投诉商品不同类 → 驳回，且留下失败记录
- 闲鱼二手闲置商品，**必须先排除权利用尽**，否则极易被申诉翻盘
- 重复投诉同一链接 → 判定滥用

## 拼多多

**通道**：拼多多知识产权保护平台

**特点**：
- 需单独注册账号并完成权利人认证
- 对**价格异常 + 销量大**的假冒线索响应较快
- 平台对"低价白牌"容忍度较高，标题未直接出现商标时通过率明显下降

**常见坑**：
- 标题用"同款""同风格的"规避表述时，仅靠标题难以认定 → 需靠主图盗用走著作权路径
- 拼多多商家申诉积极，授权类申诉较多，需提前核验授权链真伪

## 京东

**通道**：京东知识产权维权平台

**特点**：
- 需注册认证，权利备案后发起
- 自营与 POP 店处理路径不同
- 对商标权和著作权响应较好，专利权门槛高

**常见坑**：
- 授权专卖店等白名单店铺误投 → 影响与平台的合作关系
- 京东对投诉方资质审核较严，授权链不完整直接驳回

## 抖音电商 / 快手电商

**通道**：抖音电商知识产权保护中心 / 快手电商知识产权保护平台

**特点**：
- 需单独注册认证 + 权利备案
- **直播和短视频内容侵权需走内容举报，与商品投诉是两套入口**
- 商品链接审核周期略长于货架电商

**常见坑**：
- 达人带货的链接，投诉后可能只是断开达人链接，商品本身仍在
- 直播切片/录屏证据需带日期与账号信息，否则不被采信
- 店铺名称含商标但商品未使用 → 走"店铺信息侵权"而非"商品侵权"

## 小红书

**通道**：站内举报入口 + 版权/商标投诉邮箱并行

**特点**：
- 没有成熟的统一 IP 平台，入口分散，处理周期长
- 笔记内容侵权优先级高于商品链接
- 对**盗图类著作权投诉**响应最好

**常见坑**：
- 只走站内举报容易石沉大海，需同步邮件投诉并留痕
- 种草笔记属"站外社交"渠道，删除快，**固证优先级最高**

## 微信生态

**通道**：微信品牌维权平台（商标/版权）+ 视频号小店、小程序各自入口

**特点**：
- 需完成**品牌维权账号认证**，商标权与著作权分开申请
- 可覆盖公众号、小程序、微信个人号/群、视频号
- 对仿冒公众号名称、小程序名称响应较好

**常见坑**：
- 微信社群、个人号转发的内容，投诉难度远高于公众号文章
- 视频号小店的商品链接与内容投诉分属不同入口，容易走错
- 未做品牌认证前几乎无法发起商标类投诉

## 独立站（无平台通道）

**这不是"投诉"，是"打它的基础设施"。** 没有平台审核员可说服，只能施压供应链。

| 施压对象 | 手段 | 效果 |
|---|---|---|
| 域名注册商 | WHOIS 查注册商，提交侵权/滥用投诉 | 命中即致命，但注册信息常隐藏 |
| 托管商 / 云厂商 | abuse 投诉 + DMCA 通知（境外） | 中等，需提供完整权属材料 |
| CDN（如 Cloudflare） | 提交侵权投诉 | 中等 |
| 支付渠道（PayPal / Stripe / 收单机构） | 知识产权侵权投诉 | 高，冻结收款最有效 |
| 应用商店（若是 App） | 应用市场侵权投诉 | 高 |
| 搜索引擎 | 侵权内容移除申请 / 关键词投诉 | 辅助 |

**关键**：独立站证据**删除极快**，必须在接触对方之前完成全部固证。

## 跨境平台

**核心前提：先做品牌备案，否则几乎无法投诉。**

| 平台 | 体系 | 前提 |
|---|---|---|
| Amazon | Brand Registry + Report a Violation | 需有效商标（多国注册） |
| eBay | VeRO 计划 | 需加入 VeRO |
| AliExpress | 知识产权保护平台（阿里系） | 权利备案 |
| Shopee / Lazada | 各自 IP 投诉通道 | 需当地或目标国权利 |
| TikTok Shop | 各站点 IP 保护中心 | 需当地权利 + 备案 |

**常见坑**：
- **商标地域性是硬约束**——中国注册商标不能用于投诉美国站
- 跨境取证需符合当地规则，公证要求更高
- 时差与语言导致处理周期成倍拉长

## 维护建议

1. 每个平台**按实际入口维护一份指引**，注明所需材料与当前审核周期
2. 每次投诉结束回填：提交时间、受理编号、结果、驳回理由
3. **定期复盘成功率**，提炼可复用的话术与材料模板
4. 同一案件的投诉操作**指定专人跟进**，避免重复投诉影响账号权重
5. 本表每季度复核一次，过期未核实的标注「待核实」
